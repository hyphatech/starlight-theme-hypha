## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `hue` | `number` | `225` | The night's hue, in degrees |
| `links` | `{ label; href; icon? } list` | `[]` | The header's, menu's and footer's links |

## Icons

A link's icon is one of `archive`, `book-open`, `code-xml`, `globe`,
`layers` and `rss`.
