## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `hue` | `number` | `225` | The hue, in degrees |
| `brand` | `string` | none | A name before the site's title |
| `search` | `boolean` | `true` | Search in the header |
| `github` | `string`, or `{ repo; stats }` | none | The repository, as `owner/name`, with its version, stars and forks |
| `tabs` | `boolean`, or an icon by label | `false` | The sidebar's top-level groups as tabs under the header |
| `links` | `{ label; href; icon? }[]` | `[]` | Links in the header |

## Icons

An icon is one of Lucide's: `archive`, `blocks`, `book-open`, `boxes`,
`code-xml`, `component`, `compass`, `file-text`, `globe`, `graduation-cap`,
`house`, `layers`, `library`, `list-checks`, `map`, `newspaper`, `play`,
`puzzle`, `rocket`, `rss`, `scroll-text`, `settings`, `terminal` and
`wrench`.
