## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `hue` | `number` | `225` | The night's hue, in degrees |
| `github` | `string` | none | The repository, as `owner/name`, with its version, stars and forks |
| `tabs` | `bool` | `false` | The sidebar's top-level entries as tabs under the header |
| `links` | `{ label; href; icon? } list` | `[]` | The header's and the menu's links |

## Icons

A link's icon is one of `archive`, `book-open`, `code-xml`, `globe`,
`layers` and `rss`.
