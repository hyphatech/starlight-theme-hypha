## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `hue` | `number` | `225` | The night's hue, in degrees |
| `github` | `string` | none | The repository, as `owner/name`, with its version, stars and forks |
| `tabs` | `bool`, or an icon by label | `false` | The sidebar's top-level entries as tabs under the header |
| `links` | `{ label; href; icon? } list` | `[]` | The header's and the menu's links |

## Icons

A link's or a tab's icon is one of lucide's: `archive`, `blocks`,
`book-open`, `boxes`, `code-xml`, `component`, `compass`, `file-text`,
`globe`, `graduation-cap`, `house`, `layers`, `library`, `list-checks`,
`map`, `newspaper`, `play`, `puzzle`, `rocket`, `rss`, `scroll-text`,
`settings`, `terminal` and `wrench`.
