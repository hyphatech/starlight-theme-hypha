The navigation sits in the page's margin, the text at its measure, and the
page's contents beside it.

## Install

Add the plugin to Starlight's plugins.

```js title="astro.config.mjs"
starlight({
  title: "Docs",
  plugins: [starlightThemeHypha({ github: "acme/widgets" })],
});
```

### The hue

Every surface, line and text colour turns on one number, `hue`, in degrees.

- 225, a blue, is the default.
- Any other sets a site apart.
