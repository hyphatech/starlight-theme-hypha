---
title: Tokens
description: The CSS custom properties a site may set.
---

Set any of them on `:root` in a sheet in Starlight's `customCss`.

| Token | Used for |
|---|---|
| `--color-ivory` | The background |
| `--color-ink` | Text |
| `--color-graphite` | Secondary text and icons |
| `--color-rule` | Lines and borders |
| `--color-accent` | Focus, selection and search matches |
| `--color-panel` | Code, cards and controls |
| `--color-raised` | Inline code and the current item |
| `--radius-control` | Buttons and fields |
| `--radius-panel` | Panels |
| `--container-page` | The page's width |
| `--measure` | The text's width |
