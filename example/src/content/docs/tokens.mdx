---
title: Tokens
description: The CSS custom properties a site may set.
---

Each is named under the theme's prefix. Set any of them on `:root` in a
sheet in Starlight's `customCss`.

| Token | Used for |
|---|---|
| `--hypha-color-ivory` | The background |
| `--hypha-color-ink` | Text |
| `--hypha-color-graphite` | Secondary text and icons |
| `--hypha-color-rule` | Lines and borders |
| `--hypha-color-accent` | Focus, selection and search matches |
| `--hypha-color-panel` | Code, cards and controls |
| `--hypha-color-raised` | Inline code and the current item |
| `--hypha-radius-control` | Buttons and fields |
| `--hypha-radius-panel` | Panels |
| `--hypha-container-page` | The page's width |
| `--hypha-measure` | The text's width |
