The theme sets Starlight on hypha.pub's grid: the navigation in the page's
margin, the text at its measure, the page's contents beside it.

## Install

Add the plugin to Starlight's own list, with the project's links.

```js title="astro.config.mjs"
starlight({
  title: "example",
  plugins: [hypha({ links: [{ label: "GitHub", href: "https://github.com/hyphatech/example", icon: "code-xml" }] })],
});
```

### The hue

The night turns on one number, `hue`, in degrees. Every surface, line and
text colour follows it.

- 225, a reference's blue, is the default.
- Any other sets a project apart.
